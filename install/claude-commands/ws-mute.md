description: 静音 / 取消静音本机参与的协作或讨论（用法：/ws-mute [名称或标识…]）
---
<!-- waystation-managed-command -->
用户要静音或取消静音某条协作 / 讨论。参数原文：$ARGUMENTS

流程：

1. 若本会话没有 waystation 工具（`mcp__waystation__*` 不存在），提示用户：本会话未加载驿站工具，请**新开**一个 Claude Code 会话再试，不要继续。
2. 调用 `ws_list_collabs`，把本机参与的协作与讨论列给用户看：一行一条——`名称 — 类型（讨论 / 协作）— 状态`；不要把原始 JSON 贴给用户。（列表不含静音状态——静音开关为纯本机行为、未随列表暴露；设置与取消都是幂等的，对未静音条目执行取消同样安全。）
3. 敲定目标与动作：
   - 参数指明了名称或标识 → 对号入座（名称精确 → 前缀/包含）；对不上或有多重含义 → 列候选问用户，不要猜。
   - 没指定 → 用 AskUserQuestion 先选目标（条目超过 4 个时改文本列全清单请用户点名），再确认动作（静音 / 取消静音）；用户本意不明就当场问，不要替他默认。
4. 调用 `ws_set_mute`：`collabId` = 选中条目的标识，`muted` = true（进入静音）/ false（取消静音）。这是纯本机开关——不广播、对端无感、跨会话保留。
5. 回执：说清「xxx 已静音 / 已取消静音」；顺带一句行为说明——静音期实时内容（讨论帖、协作内容消息）不再注入本会话，**结束、邀请与治理等待办照常注入**；补看走 `ws_view_ledger`（讨论）/ `ws_check_inbox`（协作）。取消静音时返回的一行「静音期间新增 N 条」摘要照实转达。
6. 工具报错（没有该协作等）原文转述，不要自行重试。
