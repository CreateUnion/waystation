---
description: 列出局域网在线驿站（可协作对象）
---
<!-- waystation-managed-command -->
用户想看局域网里有哪些驿站在线可协作。调用 waystation 的 `ws_list_hosts` 后以人话列表呈现。

1. 若本会话没有 waystation 工具（`mcp__waystation__*` 不存在），提示用户：本会话未加载驿站工具，请**新开**一个 Claude Code 会话再试，不要继续。
2. 调用 `ws_list_hosts`。这是一次现场扫描（广播段扫 + 已知主机单播兜底），要等几秒才有结果，属正常。顺手调一次 `ws_status`：若载荷带 `identityHint`，在列表上方转达一次（想改名就帮他写入 config.json 的 `identityName`，说明**下次会话生效**）。
3. 呈现规则：最上方先给本机行——`本机 — <身份名>（端口 <port>；活跃终端 <sessionCount>：<会话标识前 8 位，多个逗号分隔>）`；本机载荷不含地址，只报端口；活跃终端为 0 时如实写「活跃终端 0」（不省略本机行）。随后一行一个驿站——`身份名 — 地址:端口（参与协作数 n）`；条目的 `sameMachine` 为 true 时在身份名后标「（本机·另一数据根）」；`endpoints` 有多个时全部列出；不要把原始 JSON 贴给用户。扫描结果本就是现场在线名单，不必标注时间。
4. 没有其他驿站（`hosts` 为空）：说「未扫到其他在线驿站」（本机行照常给出），附一句排查提示——对方机器的 Claude Code 会话是否开着（驿站随会话存在）、两端防火墙是否放行（安装脚本当时打印过放行指引）；**不要自行修改网络/防火墙设置**。
5. 结尾一行提示：发起协作用 `/ws-collab <项目名> <主题…> [协作者…]`（不写协作者会弹出在线驿站多选）。
