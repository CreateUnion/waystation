---
description: 列出局域网在线驿站（可协作对象）
---
<!-- waystation-managed-command -->
用户想看局域网里有哪些驿站在线可协作。调用 waystation 的 `ws_list_hosts` 后以人话列表呈现。

1. 若本会话没有 waystation 工具（`mcp__waystation__*` 不存在），提示用户：本会话未加载驿站工具，请**新开**一个 Claude Code 会话再试，不要继续。
2. 调用 `ws_list_hosts`。这是一次现场扫描（广播段扫 + 已知主机单播兜底），要等几秒才有结果，属正常。
3. 呈现规则：一行一个驿站——`身份名 — 地址:端口（参与协作数 n）`；`endpoints` 有多个时全部列出；不要把原始 JSON 贴给用户。扫描结果本就是现场在线名单，不必标注时间。
4. 列表为空：说「未扫到在线驿站」，附一句排查提示——对方机器的 Claude Code 会话是否开着（驿站随会话存在）、两端防火墙是否放行（安装脚本当时打印过放行指引）；**不要自行修改网络/防火墙设置**。
5. 结尾一行提示：发起协作用 `/ws-collab <身份名> <项目名> <主题>`。
