description: 会话级邀请免确认开关（用法：/ws-auto-accept-invites [on|off|status]）
---
<!-- waystation-managed-command -->
用户要控制本会话的邀请免确认开关。参数原文：$ARGUMENTS

流程：

1. 若本会话没有 waystation 工具（`mcp__waystation__*` 不存在），提示用户：本会话未加载驿站工具，请**新开**一个 Claude Code 会话再试，不要继续。
2. 解析参数（只认这三种，不猜）：
   - 空参数或 `on` → `mode: 'session'`（开启）；
   - `off` → `mode: 'off'`（关闭）；
   - `status` → `mode: 'status'`（查询）。
   - 其他值 → 不调用工具，向用户确认要开启、关闭还是查询。
3. 调用 `ws_allow_next_invite`，参数 `{ mode }`。
4. 回执按结果如实转述：
   - 开启成功：说明**只对当前会话生效**，本会话收到邀请时可以直接同意、不再逐条向用户确认；**拒绝邀请仍会先向用户确认**。失效条件：会话结束、核心重启、或用户执行 `/ws-auto-accept-invites off`。开启后不需要再对每条邀请说“无需确认”。
   - 关闭成功：说明已恢复逐条确认。
   - 查询：如实说当前是「已开启」还是「未开启」，并重复上面只免同意、拒绝仍确认的边界。
5. 工具报错（无会话标识、mode 非法等）原文转述，不要自行重试或换参数；不要把这个开关扩展到移交 / 接管等治理确认——那些始终需要各自的一次性令牌。
